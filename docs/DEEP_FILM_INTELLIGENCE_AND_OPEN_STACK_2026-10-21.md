# ZX7 studio — independently checked film-field research (21 October 2026)

## Original owner mandate

The owner explicitly wants a singular **deeply competent film/editorial creative intelligence**, independent like the world's best filmmaker/editor/cinematographer/graphic and 3D artist, free to conceive extraordinary original works across any medium and choose its own tools. Not another generic coding agent, fixed 2D cards, five-shot/15-second ad script, or endlessly hardcoded creative rule repairs. No mandatory paid subscriptions or GPU bills. Respect media rights, verified factual claims and historical accepted voice/audio samples. New conversations should read the repo-root `ZX7_START_HERE.md` before considering implementation.

## Reliable research, source inspected (not just search snippets)

1. **Co-Director**, Ya-Le Song et al., 2026, https://arxiv.org/abs/2604.24842, https://co-director-agent.github.io/ . Consensus full record ID `6fc24099b3e2595ebb92345e0c02bfaf` retrieved. Global artistic strategy search (multi-armed bandit) and local multimodal critique/refinement reduce semantic drift and cascading mistakes versus deterministic prompting chains. The project page's **subjective MOS 3.96 vs MovieAgent 3.22** is author-reported on a particular 400-scenario benchmark, not a guaranteed ability to outperform humans. Google demo code uses model services and is NOT a proven cost-free end-to-end backend. **Transferable idea:** a single film-brain may propose genuinely different creative hypotheses, see encoded visual output, reconsider specific failures and preserve coherent subject/story across edits.
2. **MUSE**, Wen-Zhang Sun et al., 2026, https://arxiv.org/abs/2602.03028, full Consensus record `411c64648ad75670beb3ecef574d2f5c`. Identifies the intent-to-execution gap: identity/spatial/temporal drift across long stories. Uses plan-execute-verify-revise with feedback from actual generated media; MUSEBench proposes reference-free metrics validated against human opinions. **Do not confuse creative choices with rigid templates**: invariants apply to subject identity and authored intent only.
3. **Camera Artist**, Hao Hu et al., 2026, https://arxiv.org/abs/2604.09195. Recursive cross-shot storyboarding and explicit cinematography grammar improve narrative continuity and filmic expression in evaluated conditions. Open paper is not proof of a small usable no-cost Director checkpoint.
4. **Anim-Director**, Yunxin Li et al., SIGGRAPH Asia 2024, Consensus full paper `7fbdead4c7745ec298dc5898e7a2ce13`; LMM-driven autonomous animated scenes use consistent identities and iterative image quality evaluation. Has named specialist generation interfaces; it is not a freely verified full actor-film editor.
5. **POLARIS**, 2026, https://arxiv.org/abs/2606.04095, https://huggingface.co/rishanthrajendhran/POLARIS-9B. The paper reports literary preference over its base Qwen3.5-9B but has NOT shown genuine video editing or cinematography superiority. Official metadata **gated=true, license=other**, revision `a297c82724bbe7e062341ce6eb5d85943274f2a7`, so **not legally authorized for automatic free integration**. Use research method only if rights allow, not weights by guessing/bypassing terms.
6. **ShotVL-3B**, https://huggingface.co/Vchitect/ShotVL-3B, revision `dc9888b77c5a8e06f267d21132ee197055c7f1e4`, Apache-2.0, ungated. Strong film-shot recognition on its original benchmark but independent work questioned reasoning robustness. Cannot autonomously direct a great film or replace one integrated Director.
7. **Q-ReAlign Mini ~0.8B**, https://huggingface.co/q-future/Q-ReAlign-Mini-0.8B, Apache-2.0, ungated. Perceptual visual aesthetics/quality, NOT global original narrative. Only use if actual visual evidence demands specialist scores.
8. **One general 9B**, `unsloth/Qwen3.5-9B-GGUF`, Apache-2.0, pinned GGUF 5.68GB, successfully run on 4-core GitHub public Linux CPU. Actual independent two-brief benchmark [run 39536516419](https://github.com/oyzitjfzj/Ad/actions/runs/39536516419): real authored shots saved; FOLD visual invented physical notebook cover texture and depended on unprovided live transit footage. DNS attempted a book/map metaphor but inferred an error interface, physically over-dramatized TTL and wasn't fully structured (numeric scene id). Both rejected. This model is **not accepted** as a premium film director despite competent English. Different tasks still showed 6 scenes each; no code imposed six, but candidate appears stylistically conventional.
9. **Independent creative-writing 9B**: https://huggingface.co/DavidAU/Qwen3.5-9B-The-Defiant-Fable-Uncensored-Heretic-NEO-IMATRIX-MAX-MTP-GGUF , revision pinned to `d5f3139249b7ee2535c20ab81125c9a6ab0c4915`. Hugging Face Alexandria metadata: **gated=false, license=apache-2.0**, original producer-provided license requires normal independent audit; Q4_K_M and `mmproj-F16.gguf` files exist in repo. Candidate is a *creative-writing finetune* (not a proven cinematography model) and is tested for cinema, credibility, video feedback and control. **Never promote an "uncensored" model automatically; retain factual/rights/access/tool safety checks.** See [real audition run 39539083463](https://github.com/oyzitjfzj/Ad/actions/runs/39539083463). An independent actual encoded-frame critique trial also started [run 39539553556](https://github.com/oyzitjfzj/Ad/actions/runs/39539553556). At writing, these runs may still be underway: check live GitHub before claiming any film/quality result.
10. **Smaller 4B creative-writing SFT**, `mradermacher/Qwen3-4B-CreativeWriting-SFT-GGUF`, ungated but **license missing in Hub metadata**; cannot declare full commercial reuse permission. Requires license provenance verification before runtime selection.
11. **Free editing infrastructure**: [FireRed-OpenStoryline](https://github.com/FireRedTeam/FireRed-OpenStoryline) (Apache-2.0 GitHub repo, actual natural-language editor with media search, timeline and style refinements); README explicitly warns that AIGC transitions rely on **high-cost external video services**, so free core does NOT make every visual generation free. [HKUDS/ViMax](https://github.com/HKUDS/ViMax) (MIT code; reference real LLM/image/video generator integration uses paid hosted APIs); [Google genmedia-izumi-agent](https://github.com/GoogleCloudPlatform/genmedia-izumi-agent) (Apache-2.0 code but production model costs vary). Reuse their rights-cleared/offline technical ideas or components after adapter review, NOT full paid pipelines, invented credits, or their genre defaults.
12. **Generation model** [Wan2.1-T2V-1.3B](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B) is Apache-2.0 text-to-video, but actual GPU memory/time at acceptable quality is unproven on our public GitHub CPU. There is no confirmed zero-cost always-on GPU. [LTX-Video](https://huggingface.co/Lightricks/LTX-Video) official hub metadata `license=other`, so its permitted use must be investigated before making it a default.
13. **Truly small multimodal reviewer**, [SmolVLM2-2.2B-Instruct](https://huggingface.co/HuggingFaceTB/SmolVLM2-2.2B-Instruct), Apache-2.0 and ungated; useful to understand film video but not itself a world-class editor. Prefer one capable multimodal artistic brain if it can pass real footage inspection.

It critiques visual meaning/continuity, but cannot pretend to hear audio or watch every frame from a two-frame preview. Later add genuine synchronized audio/VLM audition and targeted retakes.

## Research conclusion / choice so far

There is **no demonstrated single free permissively licensed sub-10B model** that makes truly original, highly beautiful, artistically coherent, accurate *finished* multi-genre films, real 3D, motion VFX and audiovisual edits at superhuman expert level. This remains an ambitious research/engineering goal, not a documented product. Small specialists can beat much larger general models on **narrow benchmarks**; that is encouraging but not proof of cross-domain cinematographic creativity.

The actionable direction is **ONE film-native thinking and observing brain** (trained or adapted on rights-cleared film/visual editorial decisions), connected to existing multi-engine editable media tools, with global story imagination, real-frame inspection, continuity/factual checks, and audience/human aesthetic assessment. No hardcoded creative checklist or special template can substitute for this intelligence. Do not adopt a model until its *actual independent films* are convincingly good. Keep safety/rights checks in code because those are technical verification, not the art.

Test more than one genre and ultimately render actual coherent films. Explicitly retain human creative acceptance as separate from technical success.
